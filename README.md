# العوني ستور — Complete

هذه نسخة Full-Stack قابلة للتشغيل، تشمل واجهة المتجر وAPI وقاعدة بيانات ولوحة الإدارة ونظام الطلبات والكوبونات، مع تكامل اختياري مع Stripe Checkout.

## التشغيل
1. ثبّت Node.js 20+.
2. انسخ `.env.example` إلى `.env`.
3. غيّر `JWT_SECRET` إلى قيمة عشوائية طويلة.
4. غيّر `ADMIN_EMAIL` و`ADMIN_PASSWORD`.
5. نفّذ:
   npm install
   npm start
6. افتح:
   http://localhost:3000

عند أول تشغيل، ينشأ حساب المدير من قيم ADMIN_* إذا لم يكن البريد موجوداً.

## الدفع الحقيقي
الدفع غير مفعل افتراضياً. لتفعيله:
- أنشئ حساب Stripe مناسب لبلدك ومنتجاتك.
- ضع STRIPE_SECRET_KEY في `.env`.
- ضع PUBLIC_URL على نطاق HTTPS الحقيقي.
- أنشئ webhook للعنوان:
  https://YOUR-DOMAIN/api/stripe/webhook
- ضع STRIPE_WEBHOOK_SECRET.
- أعد تشغيل الخادم.

لا تحفظ أرقام البطاقات أو CVV في قاعدة بياناتك. Stripe Checkout يتولى بيانات البطاقة.

## نشر الإنتاج
استخدم HTTPS، reverse proxy مثل Nginx/Caddy، قاعدة بيانات مُدارة/نسخ احتياطية، أسرار بيئية آمنة، مراقبة، وسياسة خصوصية وشروط استخدام وصفحة تواصل. راجع القوانين والضرائب وحقوق بيع المنتجات الرقمية في بلدك.

## ما ينقص قبل إطلاق تجاري واسع
- بريد/OTP واسترجاع كلمة المرور.
- نظام شحن/تسليم إذا كان هناك منتجات مادية.
- تسليم تلقائي للأكواد الرقمية من مخزون آمن.
- سجل تدقيق للإدارة.
- صلاحيات متعددة للموظفين.
- PostgreSQL/Redis عند زيادة الحمل.
- خدمة بريد transactional.
- CDN وتخزين صور خارجي.
- اختبارات آلية وCI/CD.
